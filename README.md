# PixelMarks

Free and open-source, privacy-first, local-first bookmark manager for Android.

Your bookmarks live entirely on your device — no account, no cloud, no tracking.

## Features

### 📚 Bookmark Management
- Save links from any app via the Android **share sheet**
- Automatically fetches page **title, description & favicon**
- Mark bookmarks as **favorites** and **pin** them to the top
- Track **visit counts** and last visits
- Edit bookmarks with notes, collections and tags
- **Trash** — deleted bookmarks are recoverable

### 🗂️ Organize
- **Collections** to group related bookmarks
- **Tags** for flexible labeling across collections
- Sort and filter options for every view

### 🔍 Find Anything Fast
- Instant **full-text search** across titles, URLs and notes
- Filter by collection, tag, favorite, and more

### 🔒 Privacy & Security
- **Private Mode** — a secure folder for sensitive bookmarks, unlocked with biometrics or a password
- **App Lock** — protect the whole app with fingerprint or device credentials

### ⏰ Reminders
- Set reminders on bookmarks so you never forget to revisit a link
- Notifications work reliably even after a device reboot

### 💾 Backup & Portability
- **HTML import & export** — fully compatible with the standard browser bookmark format (Chrome, Firefox, etc.)
- **Local backup & encrypted export**
- **Google Drive backup** — optional, only if you turn it on

### 💻 Connect to PC
- Pair your phone with your computer and manage bookmarks from a browser
- Works over your local network — no internet, no account, end-to-end pairing security
- Manage connected devices from the app

### 🌐 Built-in Browser
- Open links inside PixelMarks with its own browser screen

### 🔄 Always Up to Date
- The app checks for new releases on GitHub automatically and lets you update with one tap

## Technology

- **Language:** Kotlin
- **UI:** Jetpack Compose + Material 3
- **Architecture:** Clean Architecture (MVVM + Repository + Local-First)
- **Database:** Room
- **Minimum SDK:** Android 7.0 (API 24) · **Target:** Android 15 (API 35)
